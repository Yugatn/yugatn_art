# Yugatn Spiral

Version: 1.0 (prototype)  
Family: Yugatn Spiral  
Style: Regular  
Format: TrueType (.ttf)  
Coverage: Latin uppercase/lowercase, Cyrillic glyphs, digits, and selected punctuation.

## Design

A hand-drawn display font inspired by the supplied Yugatn Spiral character-sheet concept: thin angular strokes, irregular hand-built geometry, endpoint dots, small crossbars, and spiral details in selected glyphs.

## Install

1. Download `YugatnSpiral-Regular.ttf`.
2. On macOS, double-click the file.
3. In Font Book, choose **Install Font**.
4. Restart the target creative application if the font does not appear.

## Prototype status

This is an initial usable prototype, not a finished commercial type family. Some glyph shapes and punctuation need manual proofing; spacing and kerning are preliminary. The poster reference is an artistic concept sheet, not a precise vector font source.
